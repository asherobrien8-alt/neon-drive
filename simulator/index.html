Things to try
  • Search: LIBRARY → Search. VOL spins the letter, PLAY adds it, BACK deletes. Hold PLAY (or spin to GO>) for results.
  • A-Z jump: open any long list (Library → Artist, or All Songs) and hold PLAY.
  • Volume runner: play a song, then tap VOL+ / VOL− on Now Playing.
  • Other themes: SETTINGS → Interface → Theme.
  • Keyboard: ↑/↓ volume keys, Enter PLAY (hold for A-Z), Backspace BACK, M MENU.

The screen is drawn by ReChord's own code compiled to WebAssembly — the same screens, theme engine and library index that run on the player. Only the hardware is pretend: there's no audio, and songs "play" on a timer.
